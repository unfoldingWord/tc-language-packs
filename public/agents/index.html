Use it with your agent

Two skills teach an AI agent to read packs on your computer, with no internet: one helps a translator with a passage, the other helps a developer build with packs.

Pick your agent
Claude Code · tc-language-packs-translatoroffline
Translator

How should I translate «the grace of God has appeared» in Titus 2:11? In my language grace can't appear.

Agent 
langpack.py context packs/ --ref "TIT 2:11"

Paul speaks of the grace of God as if it were a person who arrived (figs-personification). The note suggests «God is now offering his grace»; the UST says «God is offering to save everyone as a gift that no one deserves». χάρις appears in 148 verses of 23 books; in Titus also in 1:4, 3:7 and 3:15.

Two skills, one for each job

For translators tc-language-packs-translator

Gives the agent the whole context of a verse in one call: the verse in every text on your computer, the Greek or Hebrew word by word with its lexicon, the notes and the words they explain, the questions, the key terms, and where each word appears in other books.

«What does the washing of regeneration mean in Titus 3:5?»

«Where else does Paul use this word for grace, and how did the ULT translate it?»

For developers tc-language-packs-dev

Teaches a code agent the format: files, manifest, cache keys and their stamps, versions, parts and the parts server, the v3 word index, the TypeScript packages and the views translation-helps-mcp serves.

«Write a Node script that prints a verse and its notes from these parts.»

«Open packs into IndexedDB in my app and refuse other code versions.»

Pick your agent

Claude Code

Installs both skills as one plugin. Paste the line in Claude Code.

/plugin install tc-language-packs --marketplace unfoldingWord/tc-language-packs

Then ask about a verse, with your packs in the folder you work in.

Codex, Cursor, Gemini CLI

They read skills from a folder. Download one or both, and unzip them into your project's .agents/skills/.

.agents/skills/tc-language-packs-translator/SKILL.md
.agents/skills/tc-language-packs-dev/SKILL.md

Translator skill (.zip, 17 KB) · Developer skill (.zip, 26 KB)

Gemini CLI can also install from the repository:

gemini skills install https://github.com/unfoldingWord/tc-language-packs.git --path plugins/tc-language-packs/skills/tc-language-packs-translator

Any MCP client

translation-helps-mcp answers with Bible texts and helps over the internet; its notes and word links come from packs. Add it as a remote server (Streamable HTTP).

https://tc-helps.mcp.servant.bible/v2/mcp

In Claude Code:

claude mcp add --transport http translation-helps https://tc-helps.mcp.servant.bible/v2/mcp

Your packs, your computer

The skills read packs from a folder with Python alone. Nothing goes to a server, and they work where there is no signal. Packs are modular, so every answer says which books are not on your computer.
