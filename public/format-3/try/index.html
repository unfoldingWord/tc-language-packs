Try a pack

Take a language into this browser, then ask it what a translator would ask: a verse with its notes, a word through the whole Bible, an article, the people and places of a book. It runs here, on the same library an app uses, and keeps working with no internet once it is downloaded.

Take a language into this browser

Reading the catalog from the test server…

Besides the book, the download brings what every book shares: the Greek or Hebrew of that book, the map of the whole Bible, the topics, and the key-term and Academy articles. Every catalog is checked against the publisher’s signature before anything is kept.

Step 2

Ask it

Use it from your assistant

The same packs, inside the AI assistant you already use: Cursor, Claude Desktop, Claude Code, or a free one that runs a model on your own computer, such as Atomic Chat or LM Studio. A small server on your computer keeps the packs in a folder and answers the assistant’s questions. With a local model, nothing leaves the computer once the language is downloaded.

  1. Install Node.js

    Version 20 or later, from nodejs.org. The server is one file that Node runs.

  2. Download the server

    tc-packs-mcp.mjs · 1.1 MB

    Keep it in a folder you will not move, for example C:\tc\tc-packs-mcp.mjs or ~/tc/tc-packs-mcp.mjs. The packs go to ~/.tc-language-packs.

  3. Add it to your assistant

    Cursor, Claude Desktop and most hosts

    In .cursor/mcp.json or claude_desktop_config.json, with the path where you saved the file:

    {
  "mcpServers": {
    "tc-language-packs": {
      "command": "node",
      "args": ["C:/tc/tc-packs-mcp.mjs"]
    }
  }
}
    Atomic Chat

    Settings → MCP Servers → add a server of type STDIO. Command: node. Argument: the path to tc-packs-mcp.mjs. Pick a model that can call tools.

    Claude Code 
    claude mcp add tc-language-packs -- node C:/tc/tc-packs-mcp.mjs

  4. Ask

    First: “Install Latin American Spanish with Titus.” It takes about a minute. Then, in your own words: “¿Qué dicen las notas de Tito 2:11?”, “How was grace translated in Titus?”, “¿Dónde más aparece la metáfora en la Biblia?”

A skill for translators

Hosts that read skills (Claude Code, Codex, Cursor) can also take a short guide that tells the assistant which tool answers which question, and to answer in the translator’s language with references. Unzip it into .claude/skills/ or .agents/skills/.

tc-packs-translator.zip

The server has nine tools: install_language, status, lookup_term, passage, across_bible, renderings, article, topics and search. It downloads from the same test server as this page. Its source is language-pack-mcp in tC Study.

What this page does

It downloads the language’s signed catalog, then only the pieces of the chosen book and the shared maps, from translation-helps-mcp-v2-preview.unfoldingword.workers.dev. That is a test server: the packs there are real, but they may change or be rebuilt.

Everything is kept in this browser’s storage, and the questions are answered here, with no server. Nothing you type leaves the page.

The library is @bt-synergy/language-pack-client, from tC Study, packed into one file for this page. Each answer shows the call an app makes and the JSON it gets back.
